## Mobile Device Rotation Gate

#### Entry date: 7th September 2026

Back from Japan! The first entry for this week is for the mobile rotation gate. Due to the new timeline feature for the
work experience page, the mobile page will look too awkward when displayed in portrait mode. (Not that it looked good
before anyway, but this is a problem too.) Therefore, I made this gate, which prevents the user from loading the page
unless the mobile is held horizontally.

### Design & Implementation

This was quite simple, just find a nice animated icon for the page and have some text prompting the user to rotate their
device, and there we go :)
